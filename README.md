# 小蚕净化 (XiaoCanPurify)

针对小蚕霸王餐 (`com.realtech.xiaocan`) 的现代化 Xposed / LSPosed (libxposed API 102) 净化模块.

## 版本与适配

- **当前版本**: `2.1.1` (`versionCode=28`)
- **已核对宿主版本**: 小蚕霸王餐 `3.23.0` (`3070`)、`3.21.2` (`2985`)
- **系统要求**: Android 8.0+ (`minSdk=26`), LSPosed / 兼容 libxposed API 102 的框架
- **更新记录**: 完整变更见 [CHANGELOG.md](CHANGELOG.md)

- **2.1**: 适配小蚕 `3.23.0` (`3070`), 恢复「模块设置」入口和底栏「订单」标签; 补拦新版插屏/横幅广告、首页通知与会员弹窗、详情页促销气泡、福利页推广跳转与搜券退出挽留; 新增「屏蔽首页大牌券专享活动」与「隐藏底栏『订单』」; 首页去横幅后统一为浅橙底色, 修复设置页夜间模式对比度及偶发崩溃.

## 核心能力

### 1. 全局基础净化 (默认常驻)

以下全局能力始终生效, 不受单个页面布局开关影响:

- **广告过滤**: 跳过冷启动与切后台热启动开屏广告; 自动关闭穿山甲 (CSJ/Pangle)、优量汇 (GDT)、快手 (Kwad)、Sigmob、Baidu、ToBid/WindMill、Beizi 等第三方广告 Activity; 拦截 Flutter 广告插件 (`AmSdkPlugin`、`AmInterstitialAdHandler`、`WindmillAdPlugin`) 与静默任务引擎 (`SilentTaskEngine`).
- **弹窗拦截**: 拦截应用升级/强更检查、首页营销活动、红包/商城、生日/周年庆、元宝/通知、淘宝未安装领红包提示及 Kuikly / `DialogUtils` 全局营销弹窗队列.
- **网络与桥接过滤**: 注入 OkHttp 拦截器并过滤 Flutter `NativeHttpBridge`, 阻断第三方广告上报、埋点、搜索发现推荐词与提现页/提现成功弹窗广告位 (`WITHDRAWAL_SUCCESS_POPUP`、`WITHDRAWALPAGE_POPUP`、`8876` 等), 保留正常提现、订单与混合业务请求.
- **外跳与挽留保护**: 在报名发起阶段开启自动外跳保护, 拦截商家 App 自动拉起与启动确认提示 (显式手动进店或超时后放行, 不拦截支付/登录); 拦截福利网页「跳转领取大额福利」推广跳转与搜券退出挽留.

### 2. 可配置页面净化 (内置 44 项开关)

模块没有桌面图标或独立应用界面, 设置入口直接集成在小蚕内部:

- **入口路径**: 打开小蚕 → **我的** → **设置** → 在「基础设置」下方点击 **小蚕净化设置** / **模块设置**.
- **保存与生效**: 点按开关即落盘, 无需保存按钮. 其中 34 项支持**即时生效**, 其余 10 项涉及结构与初始化的规则在修改后会在底部弹出重启提示条, 点击「立即重启」即可重拉小蚕, 不影响登录状态与订单.
- **四个场景分页**:
  - **首页 (12 项)**: 净化状态栏与节日主题、隐藏搜索框营销词与右侧横幅、隐藏顶部横幅与推广背景、隐藏红包快捷菜单、隐藏信息流推广、屏蔽首页大牌券专享活动、隐藏顶部订单推广横幅、隐藏浮动入口与底部推广、屏蔽下拉第二层 (保留普通下拉刷新)、隐藏「你有一单可免单」弹窗.
  - **订单 (12 项, 含活动详情)**: 隐藏订单页挑战横条/卡片、免单邀请、列表推广图、原生广告、提示横幅、奖励操作按钮与原生上传凭证页广告占位; 隐藏活动详情页广告/促销气泡与「分享赚豆」入口; 新店推荐任务成套控制 (屏蔽任务网页含手动打开、阻止离开详情自动跳转、关闭网页退出挽留).
  - **我的 (14 项, 含会员与提现)**: 隐藏百度广告位、商业推广宫格、公告横幅、浮动入口、底部奖励推广、新手提示、快捷菜单、商家入口、服务区、图片推广、「赚钱」入口与待领徽标、提现旁会员轮播; 屏蔽会员页「激活SVIP」标签; 自动关闭提现成功页公众号关注推广.
  - **全局 (6 项)**: 屏蔽底栏推广标签 (如购物返利/抖音补贴)、独立隐藏底栏「首页」「订单」「会员」「福利」(默认隐藏「会员」「福利」, 四项全隐藏时保留「首页」, 「我的」始终保留) 以及隐藏主界面浮动推广.

> 说明: 内置设置入口、原生上传凭证页去广告与新店推荐任务相关规则仅在已核对宿主版本 (`3.23.0` / `3.21.2`) 上按精确路由和类签名启用; 宿主未匹配或关闭开关时自动原样放行, 不修改凭证提交、失败提示或正常业务路由.

## 安装与升级

1. 从 [GitHub Releases](https://github.com/Jessire/XiaoCanPurify/releases) 或 [LSPosed 模块仓库](https://github.com/Xposed-Modules-Repo/io.github.jessire.xiaocanpurify/releases) 下载最新 `XiaoCanPurify-2.1.1-release.apk`.
2. **升级提示**: `2.0` 及以上版本签名一致, 可直接覆盖升级; 若当前安装的是 `1.2` 或更早版本, 请先卸载旧版模块后再安装.
3. 在 LSPosed Manager 中启用「小蚕净化」模块, 并在作用域中勾选 **小蚕霸王餐** (`com.realtech.xiaocan`).
4. 强制停止并重新启动小蚕霸王餐即可生效.

## 开发与扩展

### 构建环境

- **JDK**: Microsoft JDK 17
- **Gradle**: 9.5.1
- **Android SDK**: `compileSdk=37`, `targetSdk=35`, `minSdk=26`
- **Xposed API**: `io.github.libxposed:api:102.0.0` / `service:102.0.0`

### 添加新净化开关

在 `LayoutSettings.Item` 中新增枚举项并指定所属 `Category` 与文案, 将其归类到 `SettingsGroups` (以及需要热生效时加入 `LayoutSettings.HOT`), 再在对应 hook 中读取 `LayoutSettings.enabled(Item.你的项)` 即可自动出现在模块设置页中. 枚举名小写为持久化键名, 请勿重命名已有枚举项.

### 回归测试

在仓库根目录运行:

```powershell
powershell -File tests/run.ps1
```

测试基于 JVM 接口替身调用生产 hook 逻辑, 用于快速回归校验, 与真机实测结果分开记录.
